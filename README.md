# Pareto.周

关注 AI 产品经理方向，把真实场景的问题做成可体验、可验证的产品。

从需求澄清、PRD 与交互设计出发，通过 RAG、Agent、人工协同与 Vibe Coding 推进产品切片。持续探索教育陪伴、本地生活与空间思考。

[个人网站与作品集](https://chouchoupareto.github.io/Pareto-Zhou/) · [AI Skills 合集](https://github.com/ChouchouPareto/pareto-skills)

## 下一步在验证什么

- **Grokking恼：**空间化思考的真实使用价值、导出与账户能力。
- **阿甘学车：**独立语义改写评测、授权题库与真实学员反馈。原题回归不冒充 RAG 召回率。
- **阿嬷学院：**v0.5.2 内测候选计划，优先课程审核、样板课与手机试学。未经专业审核的内容不作为正式培训课程。
- **团绘AI：**素材整理与创作工作流体验；公开展示不等同于真实生成服务。
