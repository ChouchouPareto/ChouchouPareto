## 正在做的产品

### Project Kin：长期个人 AI 伙伴

希望让 AI 持续理解个人处境，减少重复交代背景，在用户需要时帮助检验判断、比较选择，并根据真实反馈修正理解。家庭关系是早期切入场景，个人生活与工作是长期方向，决定权始终属于本人。

“了解我，也敢质疑我”是伙伴理念：尊重感受，同时检查判断依据，也反思 AI 自己的结论。关系与事件时间线连接前因后果，新信息可以修正旧理解，不给人贴固定标签。只想倾诉时不强行安排任务；需要时提供可拒绝的选择与节点支持。人物思考方法是未来增加视角的构想，不替人作决定。这些设计理念仍需按版本验证。

马后炮是 Kin 中“判断回看与现实反馈”的功能环节，以独立 Demo 参加中关村中客松。比赛实践展示预估记录、本人确认、结果回填与差异回看的最小闭环；V4.8 路演推演完整伙伴形态，不表示全部能力已落地。

- 已完成：原版 Web 1.3.3 最小闭环；V2.2 本地伙伴基础工程有测试与页面验收记录。
- 正在推进：产品定位与阶段方案整理，将连续判断记录融入伙伴体验。
- 下一步：目标环境模型验收、该版本线上部署和真实用户验证。授权终端记录、本地处理、线上交流是远期方向，传感器接入尚未实现。

### 团绘AI：重点产品实践

这是我迄今产品梳理最完整的一个实践。面向本地生活商家，把门店资料、品牌偏好、设计需求与历史作品组织成持续协作的项目工作空间。

普通创作以一键生图降低入口负担，专业创作分步核对事实与设计方案。门店项目连接素材、已确认资料和创作历史，本次修改不自动覆盖长期品牌记忆。

五图以 20:3 连续母版整体设计，再裁成五张 4:3 图片。目标交互探索无限画布式工作空间，让素材、方案、作品和修改通过节点连接；装修全案愿景则把五图、Logo、品牌介绍等产物纳入同一项目，按设计与反馈节点持续协作。这体现我对 AI 的理解：帮助用户完成具体事情，需要完整协作过程与可复用背景。

产品持续开发中，围绕无限画布式工作空间、局部编辑与装修全案逐步推进设计与工程搭建。本地 M1 V0.2 已建立规则与手动确认、创作快照、项目资料复用、数据库队列与五图母版基础；公开 v1.2.0 展示前端体验。自由画布、局部重绘及全案能力按阶段完善，生成效果与上线能力以实际验收为准。仅发布介绍，不上传本地资料。[查看重点案例](https://chouchoupareto.github.io/Pareto-Zhou/#project-tuanhui)
